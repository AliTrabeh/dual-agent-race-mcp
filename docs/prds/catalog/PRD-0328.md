# PRD-0328 — Help users recognize, diagnose, and recover from errors

- **PRD ID**: PRD-0328
- **Title**: Help users recognize, diagnose, and recover from errors
- **Category**: UX Heuristic (if GUI built)
- **Requirement source**: Guidelines PDF Sec.10 / Nielsen's 10 Heuristics
- **Implementation chunk**: 6 (optional)
- **Status**: Not Started (GUI optional)

## Requirement statement

IF a GUI is built, it SHOULD satisfy the heuristic: Help users recognize, diagnose, and recover from errors.

## Rationale

Guidelines PDF recommends Nielsen's heuristics; the HW PDF's GUI is explicitly optional.

## Acceptance criteria

A GUI usability self-review checks the interface against: Help users recognize, diagnose, and recover from errors.

## Test / validation method

Manual usability self-review, only if a GUI is built
