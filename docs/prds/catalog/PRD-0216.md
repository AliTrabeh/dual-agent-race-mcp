## Requirement statement

The system MUST ensure: Every agent NL message sent is logged at DEBUG level.

## Rationale

SG-T06 requires reportable run evidence; SG-C09 forbids secrets in logs; HW-F26 wants CLI evidence.

## Acceptance criteria

A unit/integration test using a log-capture fixture asserts: Every agent NL message sent is logged at DEBUG level.

## Test / validation method

Unit test with a log-capture fixture (e.g. pytest caplog)
