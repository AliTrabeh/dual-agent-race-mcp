## Requirement statement

The `decision_strategy` parameter (current default `heuristic`) MUST be sourced from config, never hard-coded.

## Rationale

HW-F25 forbids hard-coded game parameters; SG-C08 forbids magic values in source.

## Acceptance criteria

`shared/config.py` exposes `decision_strategy`; all consumers read it via config, not a literal.
