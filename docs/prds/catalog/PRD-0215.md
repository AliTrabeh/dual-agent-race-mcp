# PRD-0215 — A failed report email send is logged at ERROR level with retry count

- **PRD ID**: PRD-0215
- **Title**: A failed report email send is logged at ERROR level with retry count
- **Category**: Logging Requirement
- **Requirement source**: docs/03_architecture.md + SG-C09
- **Implementation chunk**: varies
- **Status**: Not Started

## Requirement statement

The system MUST ensure: A failed report email send is logged at ERROR level with retry count.

## Rationale

SG-T06 requires reportable run evidence; SG-C09 forbids secrets in logs; HW-F26 wants CLI evidence.

## Acceptance criteria

A unit/integration test using a log-capture fixture asserts: A failed report email send is logged at ERROR level with retry count.

## Test / validation method

Unit test with a log-capture fixture (e.g. pytest caplog)
