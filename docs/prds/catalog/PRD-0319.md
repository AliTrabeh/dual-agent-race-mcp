# PRD-0319 — Local Ollama exposed via an Nginx reverse proxy with htpasswd/Certbot is a supported option

- **PRD ID**: PRD-0319
- **Title**: Local Ollama exposed via an Nginx reverse proxy with htpasswd/Certbot is a supported option
- **Category**: LLM Connectivity Option
- **Requirement source**: HW PDF HW-F19
- **Implementation chunk**: 4,10
- **Status**: Not Started

## Requirement statement

The system MUST support, via config only, the option: Local Ollama exposed via an Nginx reverse proxy with htpasswd/Certbot is a supported option.

## Rationale

HW-F19 names 3 LLM-connectivity architectures; LLMClient must stay agnostic to the choice.

## Acceptance criteria

Switching to this option requires only a config/.env change, no code change.

## Test / validation method

Manual deployment verification plus an LLMClient interface unit test
