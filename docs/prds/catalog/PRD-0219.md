# PRD-0219 — Config load failure is logged at ERROR level before the ConfigError propagates

- **PRD ID**: PRD-0219
- **Title**: Config load failure is logged at ERROR level before the ConfigError propagates
- **Category**: Logging Requirement
- **Requirement source**: docs/03_architecture.md + SG-C09
- **Implementation chunk**: varies
- **Status**: Not Started

## Requirement statement

The system MUST ensure: Config load failure is logged at ERROR level before the ConfigError propagates.

## Rationale

SG-T06 requires reportable run evidence; SG-C09 forbids secrets in logs; HW-F26 wants CLI evidence.

## Acceptance criteria

A unit/integration test using a log-capture fixture asserts: Config load failure is logged at ERROR level before the ConfigError propagates.

## Test / validation method

Unit test with a log-capture fixture (e.g. pytest caplog)
