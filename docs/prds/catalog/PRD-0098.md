# PRD-0098 — config/setup.json: version

- **PRD ID**: PRD-0098
- **Title**: config/setup.json: version
- **Category**: Configuration Parameter
- **Requirement source**: config/setup.json + HW-F25
- **Implementation chunk**: 2
- **Status**: Not Started

## Requirement statement

The `version` parameter (current default `1.00`) MUST be sourced from config, never hard-coded.

## Rationale

HW-F25 forbids hard-coded game parameters; SG-C08 forbids magic values in source.

## Acceptance criteria

`shared/config.py` exposes `version`; all consumers read it via config, not a literal.

## Test / validation method

Unit test in tests/unit/test_shared/test_config.py
