# PRD-0118 — config/rate_limits.json: services.llm.requests_per_minute

- **PRD ID**: PRD-0118
- **Title**: config/rate_limits.json: services.llm.requests_per_minute
- **Category**: Configuration Parameter
- **Requirement source**: config/rate_limits.json + SG-C06
- **Implementation chunk**: 2
- **Status**: Done

## Requirement statement

The `services.llm.requests_per_minute` rate-limit parameter (current default `20`) MUST be centralized in JSON.

## Rationale

SG-C06 requires rate limits centralized in JSON, never hard-coded per call site.

## Acceptance criteria

`shared/gatekeeper.py` reads `services.llm.requests_per_minute` from RateLimitConfig, never a literal.

## Test / validation method

Unit test in tests/unit/test_shared/test_gatekeeper.py
