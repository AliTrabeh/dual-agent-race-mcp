# PRD-0119 — config/rate_limits.json: services.llm.requests_per_hour

- **PRD ID**: PRD-0119
- **Title**: config/rate_limits.json: services.llm.requests_per_hour
- **Category**: Configuration Parameter
- **Requirement source**: config/rate_limits.json + SG-C06
- **Implementation chunk**: 2
- **Status**: Done

## Requirement statement

The `services.llm.requests_per_hour` rate-limit parameter (current default `300`) MUST be centralized in JSON.

## Rationale

SG-C06 requires rate limits centralized in JSON, never hard-coded per call site.

## Acceptance criteria

`shared/gatekeeper.py` reads `services.llm.requests_per_hour` from RateLimitConfig, never a literal.

## Test / validation method

Unit test in tests/unit/test_shared/test_gatekeeper.py
