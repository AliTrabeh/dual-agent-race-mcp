# PRD-0222 — Secrets (tokens, API keys) are never written to any log line

- **PRD ID**: PRD-0222
- **Title**: Secrets (tokens, API keys) are never written to any log line
- **Category**: Logging Requirement
- **Requirement source**: docs/03_architecture.md + SG-C09
- **Implementation chunk**: varies
- **Status**: Not Started

## Requirement statement

The system MUST ensure: Secrets (tokens, API keys) are never written to any log line.

## Rationale

SG-T06 requires reportable run evidence; SG-C09 forbids secrets in logs; HW-F26 wants CLI evidence.

## Acceptance criteria

A unit/integration test using a log-capture fixture asserts: Secrets (tokens, API keys) are never written to any log line.

## Test / validation method

Unit test with a log-capture fixture (e.g. pytest caplog)
