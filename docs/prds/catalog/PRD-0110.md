## Requirement statement

The `github_repo` parameter (current default `https://github.com/REPLACE/REPLACE`) MUST be sourced from config, never hard-coded.

## Rationale

HW-F25 forbids hard-coded game parameters; SG-C08 forbids magic values in source.

## Acceptance criteria

`shared/config.py` exposes `github_repo`; all consumers read it via config, not a literal.

## Test / validation method
