# PRD-0120 — config/rate_limits.json: services.llm.concurrent_max

- **PRD ID**: PRD-0120
- **Title**: config/rate_limits.json: services.llm.concurrent_max
- **Category**: Configuration Parameter
- **Requirement source**: config/rate_limits.json + SG-C06
- **Implementation chunk**: 2
- **Status**: Done

## Requirement statement

The `services.llm.concurrent_max` rate-limit parameter (current default `2`) MUST be centralized in JSON.

## Rationale

SG-C06 requires rate limits centralized in JSON, never hard-coded per call site.

## Acceptance criteria

`shared/gatekeeper.py` reads `services.llm.concurrent_max` from RateLimitConfig, never a literal.

## Test / validation method

Unit test in tests/unit/test_shared/test_gatekeeper.py
