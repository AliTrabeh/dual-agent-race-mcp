# PRD-0099 — config/setup.json: grid_size

- **PRD ID**: PRD-0099
- **Title**: config/setup.json: grid_size
- **Category**: Configuration Parameter
- **Requirement source**: config/setup.json + HW-F25
- **Implementation chunk**: 2
- **Status**: Done

## Requirement statement

The `grid_size` parameter (current default `[5, 5]`) MUST be sourced from config, never hard-coded.

## Rationale

HW-F25 forbids hard-coded game parameters; SG-C08 forbids magic values in source.

## Acceptance criteria

`shared/config.py` exposes `grid_size`; all consumers read it via config, not a literal.

## Test / validation method

Unit test in tests/unit/test_shared/test_config.py
