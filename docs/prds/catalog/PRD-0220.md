# PRD-0220 — Gatekeeper queue depth is logged whenever backpressure is triggered

- **PRD ID**: PRD-0220
- **Title**: Gatekeeper queue depth is logged whenever backpressure is triggered
- **Category**: Logging Requirement
- **Requirement source**: docs/03_architecture.md + SG-C09
- **Implementation chunk**: varies
- **Status**: Not Started

## Requirement statement

The system MUST ensure: Gatekeeper queue depth is logged whenever backpressure is triggered.

## Rationale

SG-T06 requires reportable run evidence; SG-C09 forbids secrets in logs; HW-F26 wants CLI evidence.

## Acceptance criteria

A unit/integration test using a log-capture fixture asserts: Gatekeeper queue depth is logged whenever backpressure is triggered.

## Test / validation method

Unit test with a log-capture fixture (e.g. pytest caplog)
