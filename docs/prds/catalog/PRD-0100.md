# PRD-0100 — config/setup.json: max_moves

- **PRD ID**: PRD-0100
- **Title**: config/setup.json: max_moves
- **Category**: Configuration Parameter
- **Requirement source**: config/setup.json + HW-F25
- **Implementation chunk**: 2
- **Status**: Done

## Requirement statement

The `max_moves` parameter (current default `25`) MUST be sourced from config, never hard-coded.

## Rationale

HW-F25 forbids hard-coded game parameters; SG-C08 forbids magic values in source.

## Acceptance criteria

`shared/config.py` exposes `max_moves`; all consumers read it via config, not a literal.

## Test / validation method

Unit test in tests/unit/test_shared/test_config.py
