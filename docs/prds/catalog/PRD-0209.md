# PRD-0209 — Every auth failure (invalid/revoked/expired token) is logged at WARNING level

- **PRD ID**: PRD-0209
- **Title**: Every auth failure (invalid/revoked/expired token) is logged at WARNING level
- **Category**: Logging Requirement
- **Requirement source**: docs/03_architecture.md + SG-C09
- **Implementation chunk**: varies
- **Status**: Not Started

## Requirement statement

The system MUST ensure: Every auth failure (invalid/revoked/expired token) is logged at WARNING level.

## Rationale

SG-T06 requires reportable run evidence; SG-C09 forbids secrets in logs; HW-F26 wants CLI evidence.

## Acceptance criteria

A unit/integration test using a log-capture fixture asserts: Every auth failure (invalid/revoked/expired token) is logged at WARNING level.

## Test / validation method

Unit test with a log-capture fixture (e.g. pytest caplog)
