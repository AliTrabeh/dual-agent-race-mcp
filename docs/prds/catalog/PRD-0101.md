# PRD-0101 — config/setup.json: num_games

- **PRD ID**: PRD-0101
- **Title**: config/setup.json: num_games
- **Category**: Configuration Parameter
- **Requirement source**: config/setup.json + HW-F25
- **Implementation chunk**: 2
- **Status**: Done

## Requirement statement

The `num_games` parameter (current default `6`) MUST be sourced from config, never hard-coded.

## Rationale

HW-F25 forbids hard-coded game parameters; SG-C08 forbids magic values in source.

## Acceptance criteria

`shared/config.py` exposes `num_games`; all consumers read it via config, not a literal.

## Test / validation method

Unit test in tests/unit/test_shared/test_config.py
