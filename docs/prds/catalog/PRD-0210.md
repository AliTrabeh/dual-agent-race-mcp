# PRD-0210 — Every rate-limit breach is logged at WARNING level with the service name

- **PRD ID**: PRD-0210
- **Title**: Every rate-limit breach is logged at WARNING level with the service name
- **Category**: Logging Requirement
- **Requirement source**: docs/03_architecture.md + SG-C09
- **Implementation chunk**: varies
- **Status**: Not Started

## Requirement statement

The system MUST ensure: Every rate-limit breach is logged at WARNING level with the service name.

## Rationale

SG-T06 requires reportable run evidence; SG-C09 forbids secrets in logs; HW-F26 wants CLI evidence.

## Acceptance criteria

A unit/integration test using a log-capture fixture asserts: Every rate-limit breach is logged at WARNING level with the service name.

## Test / validation method

Unit test with a log-capture fixture (e.g. pytest caplog)
