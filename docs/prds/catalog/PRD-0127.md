## Requirement statement

The `services.gmail.max_retries` rate-limit parameter (current default `3`) MUST be centralized in JSON.

## Rationale

SG-C06 requires rate limits centralized in JSON, never hard-coded per call site.

## Acceptance criteria

`shared/gatekeeper.py` reads `services.gmail.max_retries` from RateLimitConfig, never a literal.
