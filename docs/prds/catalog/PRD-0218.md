# PRD-0218 — Config load success is logged at INFO level with the resolved path

- **PRD ID**: PRD-0218
- **Title**: Config load success is logged at INFO level with the resolved path
- **Category**: Logging Requirement
- **Requirement source**: docs/03_architecture.md + SG-C09
- **Implementation chunk**: varies
- **Status**: Not Started

## Requirement statement

The system MUST ensure: Config load success is logged at INFO level with the resolved path.

## Rationale

SG-T06 requires reportable run evidence; SG-C09 forbids secrets in logs; HW-F26 wants CLI evidence.

## Acceptance criteria

A unit/integration test using a log-capture fixture asserts: Config load success is logged at INFO level with the resolved path.

## Test / validation method

Unit test with a log-capture fixture (e.g. pytest caplog)
