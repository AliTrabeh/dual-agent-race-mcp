# PRD-0208 — Every MCP tool call is logged with caller identity, tool name, and timestamp

- **PRD ID**: PRD-0208
- **Title**: Every MCP tool call is logged with caller identity, tool name, and timestamp
- **Category**: Logging Requirement
- **Requirement source**: docs/03_architecture.md + SG-C09
- **Implementation chunk**: varies
- **Status**: Not Started

## Requirement statement

The system MUST ensure: Every MCP tool call is logged with caller identity, tool name, and timestamp.

## Rationale

SG-T06 requires reportable run evidence; SG-C09 forbids secrets in logs; HW-F26 wants CLI evidence.

## Acceptance criteria

A unit/integration test using a log-capture fixture asserts: Every MCP tool call is logged with caller identity, tool name, and timestamp.

## Test / validation method

Unit test with a log-capture fixture (e.g. pytest caplog)
