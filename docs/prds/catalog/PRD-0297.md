- **Category**: Parallelism Guidance

## Requirement statement

The implementation MUST follow: I/O-bound work (MCP network calls) uses async/threading, not multiprocessing (SG-C12).

## Rationale

SG-C12 distinguishes CPU-bound vs I/O-bound concurrency strategy and requires thread safety.

## Acceptance criteria

Code review of the relevant module confirms: I/O-bound work (MCP network calls) uses async/threading, not multiprocessing (SG-C12).

## Test / validation method

Code review plus a concurrency-focused integration test
