# PRD-0102 — config/setup.json: max_barriers

- **PRD ID**: PRD-0102
- **Title**: config/setup.json: max_barriers
- **Category**: Configuration Parameter
- **Requirement source**: config/setup.json + HW-F25
- **Implementation chunk**: 2
- **Status**: Done

## Requirement statement

The `max_barriers` parameter (current default `5`) MUST be sourced from config, never hard-coded.

## Rationale

HW-F25 forbids hard-coded game parameters; SG-C08 forbids magic values in source.

## Acceptance criteria

`shared/config.py` exposes `max_barriers`; all consumers read it via config, not a literal.

## Test / validation method

Unit test in tests/unit/test_shared/test_config.py
